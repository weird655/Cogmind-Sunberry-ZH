# 终端中文输入适配（实验版）

仅用于当前已验证的 Windows Beta 17.1。普通终端打开“手动指令”后，原位置出现 Unicode 输入层。
输入法负责拼音组合与候选；确认上屏后另按 Enter 提交。选词用的 Enter 不执行黑入。

输入可使用已登记的完整中文命令，或者当前菜单完整中文行。全角括号、中文弯双引号可归一化。
当前入口、机器、原生控件和选项状态必须仍然一致；中文对应多个目标或没有对应项时，不提交。
普通英文继续交给原版解析，不重新解释它。

```text
Windows Unicode 编辑层（IME 组合 / 确认）
  → 本次输入对象
  → 当前终端上下文校验
  → 当前登记的中文行 / 完整命令
  → 唯一原生命令及目标
  → 原生输入控件 setter
  → 一次正常 Enter 事件
  → Cogmind 原生解析、概率与结果
```

中文编辑用 Windows Unicode 子控件，游戏自己的单字节解析器仍然接收原生命令。
不全局拦截中文，不把任意中文逆向查整份译表，不更改随机数、警报或成功率。
现有页面的实际中文绘制结果优先登记，因此同一词的不同译法不会靠猜测反推目标。
固定手动命令来自本终端原生允许集合；Query 的菜单记录参数按当前行指向的百科 ID 核对。
Schematic、Analysis 等其他通配参数尚未接入身份适配，不能据此声称全部中文命令可用；可保留英文输入。

验证分为：纯匹配测试、独立进程中的 Unicode 编辑和原生输入控件测试、玩家实际拼音输入测试。
隔离测试截住原生 Enter 边界，只计数而不调用黑入业务，不能冒充真实输入法或黑入成功证明。
Windows 输入层可能不会进入游戏自身 F12 截图，需要显示问题时使用系统截图。

回滚：正常保存退出后，恢复更新备份中的 physfs.dll、native_zh.dll、install-state.json；勿覆盖后续新存档。
