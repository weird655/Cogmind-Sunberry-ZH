# Cogmind 中文 · 太阳莓

**按一下，让另一种语言逐字接管画面。**

![Cogmind 局内中英文逐字替换演示](assets/language-switch.gif)

**右 Alt＋F9**，局内切换中文与英文。新文字逐个替换旧文字，保留游戏的终端感。

支持已适配的物品名称、物品详情、终端正文、日志、警报与手册等界面。当前适配 **Windows · Cogmind Beta 17.1**。

## 使用

从 Releases 获取对应版本的安装 ZIP。保存退出游戏后，运行包内的安装 CMD，选择游戏目录；之后照常从游戏 EXE 或 Steam 启动。CMD 用于安装、检查和卸载，不是启动器。

第四轮增量更新基于第三轮统一版本，请按发布包说明匹配基础版本。安装前会备份存档；卸载不会覆盖之后的游戏进度。

## 本轮更新

- 统一精确匹配与动态句式的成功返回值，修复“已经译出却仍显示英文”。
- 独立日志行按自身可用宽度显示，修复中文比英文长时退回英文。
- 补上监视小队数量句式，验证运输清单、历史日志与中英切换。

已通过十二套离线回归与原生显示测试。仍可能存在未接通的界面或漏译，欢迎附截图、游戏版本和触发步骤反馈。

游戏更新后需要核验适配；目前只支持中英文切换。俄文尚需扩展字库和宽度规则，阿拉伯文还需双向排版与字形连接处理。
